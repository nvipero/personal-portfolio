Six years of set-top box development alongside rebuilding elisaviihde.fi more
than once as the web stack evolved. That meant working across the stack's
generations: from an early version built on Mustache templates and native
JavaScript, to a later web app — on a foundation originally created by
consultancy Reaktor — using Mustache together with Bacon.js for
functional/reactive JavaScript. That codebase was the one later modernised
during my 2019–2026 engagement with the same service.

I also built APIs for mobile software, contributed to UI and technical design,
and handled release deployment to servers.
